About This Project

This web application was containerised using Docker and deployed locally using Kubernetes. It demonstrates how containers package applications and how Kubernetes can manage application deployments.

What This Shows

  • Creating a simple static web application
  • Writing a Dockerfile
  • Building a Docker image
  • Running a container locally
  • Deploying the container to Kubernetes
  • Exposing the application using a Kubernetes Service
